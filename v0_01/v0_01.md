🧱 Core Engine Combination Recommendations

RPGX: The Grid and Map Backbone
This is the most fitting existing Rust library for your needs. It's specifically designed for grid-based RPGs, providing layered maps, tile effects, pathfinding, and entity movement logic. Fallout's cell-based movement and positioning form the foundation, and RPGX can directly take this over, saving you from writing your own A* and field-of-view systems from scratch. It's lightweight and modular, and won't force you into any particular rendering solution.

dramaturge: The Narrative and Dialogue Brain
The NPC independence you want—"each with their own personality, almost independent of the player"—requires a dialogue system that supports character memory, facts, relationships, and conditional branching, not just a simple dialogue tree. dramaturge does exactly this: it models characters, facts, camps, relationships, memories, and events as pure data, and evaluates conditions and applies consequences. This means an NPC can "remember" that you helped them, can "know" that you belong to a certain faction, and subsequent dialogue can be automatically gated by these states. This is the key technical foundation for achieving that "world like a novel" narrative depth.

Bevy: The Rendering and Framework Layer
If you need a modern rendering layer, Bevy is currently the most active general-purpose game engine in the Rust ecosystem. But for your needs, it doesn't need to be used as a full engine—just use it as a rendering layer and ECS framework. There's already a project called Wasteland Tactics, which is a Fallout Tactics-style tactical game built with Rust + Bevy, using Tiled maps, action points, and turn-based mechanisms, demonstrating Bevy's feasibility in this genre. You can use Bevy to display RPGX's grid and render sprites and UI, while game logic is handled by the libraries above.

gametools: The Grid and Field-of-View Supplement
If some of RPGX's grid features aren't sufficient, gametools provides very pure grid traversal, neighbor calculation, and field-of-view (FOV) algorithms (perimeter raycasting, recursive shadowcasting). It can serve as an underlying computational supplement.
⚠️ Dialogue System Alternative: Choose Based on Your Technical Preferences

dramaturge's advantage lies in data-driven narrative state, but it's not yet published on crates.io and needs to be introduced via a local path or Git. If you prefer a more "traditional dialogue tree editor" approach:

    bevy_talks: A Bevy plugin that supports authoring branching dialogue graphs in RON files, with an accompanying visual editor, suitable for those who want to design conversations through a UI interface. The downside is that the API is still young, and it leans more toward "dialogue tree" rather than "character memory."

    Urd: A dialogue scripting language that compiles to a directed graph plus a lightweight VM, supporting variables, conditionals, pattern matching, and even dice rolls. It's suitable for those willing to write dialogue in a custom scripting language, pursuing a "screenplay-like" authoring experience.

My judgment is: If your core selling point is "NPCs truly remember you and the world state changes because of it," then dramaturge is the more accurate choice; if you just want complex branching dialogue and are willing to manually manage state, then bevy_talks or Urd will be easier to get started with.
🧭 A Practical Build Path

    First, use RPGX + a minimal Bevy window to get a grid map displayed and allow a character to move cell by cell. This step validates that the "Fallout-style cell movement feel" works.

    Integrate dramaturge and make one NPC: they have a "memory fact," and after you complete an action, this fact is set, and subsequent dialogue options change accordingly. This validates the narrative loop.

    Gradually layer in combat (action points, turn-based), inventory, and skill checks. All these systems read and write the same world state, rather than being isolated features.

The core philosophy of early Fallout was "the world doesn't revolve around you, but your choices leave traces in it." The combination above can support this philosophy at the technical level: RPGX ensures the world has a solid spatial structure, dramaturge ensures the world has memory, and Bevy ensures you can see all of this.
